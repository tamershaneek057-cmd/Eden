# Eden

A tiny browser app that lets you type a message and see it echoed back by the page.

## Run it locally

1. Open a terminal in the project folder.
2. Start a local web server:

   ```bash
   python3 -m http.server 8000
   ```

3. Visit:

   ```text
   http://localhost:8000
   ```

4. Type a message in the input field and click Run.

## Files

- `index.html` — page structure
- `styles.css` — styling
- `app.js` — form behavior
